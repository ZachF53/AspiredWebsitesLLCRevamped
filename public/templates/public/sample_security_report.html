The Monthly Report, As You'd Receive It

On the first of each month, every hosting client gets a one-page summary of an automated scan of their site. This is what it looks like — the categories are exactly the real report’s; the numbers below are a representative sample, because we don’t publish real clients’ scan results.

Sample Report

Monthly Security Summary — Sample HVAC Client

Covering the previous calendar month. Illustrative numbers.

Uptime

100% across 8,640 checks this month, against a 99.9% target. Longest response time observed: 412 ms. If the site had gone down, this section names when, for how long, and what was done.

Dependency Vulnerabilities

0 critical · 0 high · 1 moderate — the moderate finding was a third-party library update, applied on the 14th. Every finding is listed with what it was and what we did; fixing them is covered by your plan, never an extra invoice.

SSL Certificate

Valid, auto-renewed on the 9th, next renewal scheduled well before expiry. Visitors never see a browser warning where your website should be.

Security Headers

All present: strict transport security, content-type protections, frame blocking, and a content security policy. These are the browser-level instructions that shut out entire classes of common attacks.

File Integrity

No unexpected changes. Every file on the server is checked against what we deployed. A tampered or injected file — how most small-business hacks announce themselves — shows up here first.

What Your Site Booked

Form submissions and call-backs, counted by the first-party tracker: quote requests, call-back asks, and which pages produced them. The measurement side of the same report — so the site’s output is a number, not a feeling.

The real report arrives by email as one page, written in plain English. When something needs attention, it says what we found, what we did, and whether you need to do anything (usually: nothing).
