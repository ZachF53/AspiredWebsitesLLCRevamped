# PageSpeed Insights verification — 2026-09-26

Closes item 4.3 of the Sept 2026 buyer-persona review implementation
plan: the review's Mobile (7.0) and Speed (8.2) scores were capped by
its raw-fetch method, not the site. This is the rendered-browser pass.

Method: PageSpeed Insights API v5, `strategy=mobile`, run against
production. Final-screenshot renders were inspected at phone width for
the homepage and the hosting page — no horizontal overflow, hero
legible, CTAs full-width.

## Remaining known finding

`color-contrast` on primary buttons: white text on brand orange
(#E8650A) measures 3.33:1 against WCAG AA's 4.5:1 for normal-size text.
Fixing it means either dark button text or a darker orange — a brand
decision, deliberately not made unilaterally. Everything else passes.
